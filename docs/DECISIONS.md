기록일: 2026-09-14

근거: `00_READ_FIRST.md`, `01_MASTER_IMPLEMENTATION_PROMPT.md` 0~3·14~15장, GitHub 저장소 상태, 이 작업 PC 조사 결과.

우선순위: 발주자가 이후 명시적으로 확정한 변경 > 구현 명세 > 검수 시나리오 > 단계 분할 > 참고 이미지.

## 2. PHASE 00에서 잠정안을 따라 한 구현 가정

발주자 확정은 아니다. 다만 다음이 동시에 성립해 **최소 WPF 기준선만** 구성했다.

- 기존 애플리케이션 코드가 없다.
- `00_READ_FIRST.md`는 기존 스택이 없으면 새 WPF 프로젝트를 가정한다.
- 이번 Worker 지시의 잠정안은 Windows 11 x64 / C# / .NET 10 LTS / WPF / 로컬 SQLite다.
- 이 PC에 Windows Desktop 런타임이 있고 GUI 세션이 있다.

| ID | 항목 | PHASE 00에서 한 일 | 확정 여부 |
|---|---|---|---|
| A01 | 대상 프레임워크 | `net10.0-windows` WPF 빈 창 + `net10.0` Core 라이브러리 | 미확정. 납품 OS가 바뀌면 폐기 가능해야 한다. |
| A02 | SDK | 작업 PC에 SDK가 없어 `Microsoft.DotNet.SDK.10` 10.0.401을 설치하고 `global.json`에 고정 | 개발 환경 조치. Preview SDK는 사용하지 않음. |
| A03 | 테스트 | xUnit 프로젝트 1개. Core가 WPF/SQLite를 참조하지 않는지 검사 | 명세의 테스트 스택을 따른 기준선. |
| A04 | SQLite / MVVM 패키지 | **아직 추가하지 않음.** PHASE 00은 데이터 모델·대량 패키지 설치를 금지한다. | PHASE 01에서 검토. |
| A05 | 제품명 FlowNote | 시안용 가칭. 상표·도메인 검증 없음 | 미확정. |

Windows 전용 납품, 암호화 없는 사내 배포, 공개 판매용 서명·업데이트·결제는 발주자 확인 없이 확정하거나 배포하지 않는다.

## 4. 참고 이미지 3장 — 실제 열람 기록

경로와 SHA-256은 `PACKAGE_MANIFEST.json`과 일치했다. 세 장 모두 컨셉 시안이며 실행 화면이 아니다.

### `references/01_product_overview.png`

읽음. 마케팅 포스터다.

- 살릴 방향: 플로팅 입력, TODO 완료 후 목록에서 숨김, 텍스트·이미지·파일 첨부, 노드가 있는 하루 타임라인, 밝은 바탕·파란 강조.
- 옮기지 않음: 산 사진·캐치프레이즈, 다운로드 배너, Jira/Notion/Slack/Google Calendar/Outlook/Confluence 로고와 동기화 문장, Windows/macOS/iOS/Android 동시 지원 표기, 사람 사진 추천 섹션.

### `references/02_timeline_concepts.png`

읽음. 타임라인 컨셉이다.

- 살릴 방향: 시각 노드와 카드, 텍스트·이미지·파일·완료를 한 흐름에 연결, 업무별 묶음, 완료가 타임라인에 남는 표현.
- 옮기지 않음: 스마트폰 프레임, 캘린더/카드/태그 보드를 V1 기본 화면으로 넣는 것, 주간 히트맵의 `7.5h` 같은 근무시간 숫자, 플랫폼 로고.

### `references/03_timeline_variations.png`

읽음. 보기 변형 시안이다.

- 살릴 방향: 시간순 목록, 업무별 그룹, 멀티미디어 카드, 완료 이력이 흐름에 남는 문장.
- 옮기지 않음: 모바일 하단 탭과 중앙 원형 추가 버튼, 소요시간 막대 캘린더, `6h 25m`·`128/42/28h` 통계, AI 문체 요약, 음성 녹음 카드, 파이 차트 인사이트, 멀티 디바이스 홍보.

시각 토큰(밝은 배경 `#F6F8FC`, 표면 흰색, 강조 `#3568E8`)은 명세 5.1을 따른다. 이미지에서 읽은 장식 통계는 앱에 넣지 않는다.

## 5. 충돌과 해결

| 충돌 | 해결 |
|---|---|
| 패키지는 스택 미확정인데 PHASE 00은 확정 시 최소 솔루션을 만든다. | 기존 코드가 없고 잠정안이 WPF이므로 기준선만 만든다. 이 문서에서 스택을 확정이라고 쓰지 않는다. |
| 참고 이미지는 모바일·연동·통계를 보여 준다. | 명세 1장과 P08을 우선한다. 이미지는 방향만 참고한다. |
| 로컬 폴더는 git 저장소가 아니고 GitHub는 비어 있다. | 코드를 원격에 덮어쓰지 않았다. 원격 초기화·푸시는 발주/작업 지시가 있을 때 한다. |
