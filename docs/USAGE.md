# FlowNote 사용 안내

기록일: 2026-09-16  
대상 빌드: `artifacts/dist/FlowNote-0.4.0-win-x64-core.zip`  
제품 기준: `docs/CORE_PRODUCT.md`

## 실행

핵심 배포(AI 모델·엔진 없음):

```powershell
powershell -ExecutionPolicy Bypass -File scripts/package-core.ps1
```

- 포터블: `artifacts/dist/FlowNote-0.4.0-win-x64-core.zip`
- 폴더 실행: `artifacts/win-x64/FlowNote.Desktop.exe`

- 일반 데이터: `%LOCALAPPDATA%\FlowNote\live`
- 데모 데이터: `.\artifacts\win-x64\FlowNote.Desktop.exe --demo` → `%LOCALAPPDATA%\FlowNote\demo`  
  격리하려면 `--data-root <빈 폴더>`를 붙인다. 샘플 하루는 데모에서만 한 번 만든다.
- `--smoke`와 `--demo`를 같이 쓰면 샘플 시딩을 하지 않는다.
- 끝내려면 메인 창의 X가 아니라 **트레이 아이콘 → 앱 종료**를 사용한다. X는 트레이로 숨긴다.

## 기록

1. 작업 영역 오른쪽 위의 **한 줄 캡슐**에 메모를 입력한다. 다른 앱을 쓰는 중에도 **Ctrl+Alt+Space**로 그 입력칸에 바로 포커스가 온다. 조합이 이미 쓰이면 설정에 안내가 뜨고, 트레이의 **기록 창**으로 연다. **Enter** 또는 인라인 기록 버튼으로 남긴다. Ctrl+Enter도 같다. 한글 조합을 확정하는 Enter는 기록하지 않는다. **Shift+Enter** 또는 로고 메뉴의 긴 메모로 여러 줄을 연다.
2. 카메라 아이콘은 **한 번 영역을 드래그**해 초안 첨부한다. 자동으로 타임라인에 올리지 않는다. 클립 아이콘·Ctrl+V·끌어다 놓기로 파일을 붙인다. 실행 파일·스크립트·바로가기는 거부한다. 파일당 25MB, 기록당 10개. 텍스트와 첨부가 모두 없으면 기록은 비활성이다. 이미지만 있어도 기록할 수 있다.
3. 업무 연결은 필수가 아니다. 로고 메뉴의 **연결 업무 선택** / **연결 해제**, 또는 본창 **이어서 기록**으로 칩을 단다. 화면에서 다른 업무를 열어 보기만 해서는 작성 중 초안이 바뀌지 않는다. 초안이 다른 업무와 겹치면 계속/재연결/취소를 고른다.
4. 저장이 되면 입력칸은 비고, `HH:mm 기록됨`은 입력칸 위의 상태 문구다. 본문에 넣지 않는다. 방금 남긴 내용은 캡슐 아래 기억판 첫 행에 바로 보인다.
5. 기억판은 최근 기록 최대 3개다. 행을 누르면 같은 패널에서 원문·첨부를 본다. 메모나 할 일 하나를 **고정한 메모 / 고정한 일**로 둘 수 있다. 새 기록이 고정을 바꾸지 않는다. **접기**는 다음 실행에도 유지된다. 다른 앱을 눌러도 기억판은 닫히지 않는다.
6. **할 일 N개**로 같은 패널을 미완료 목록으로 바꾼다. `+ 할 일 추가` 후에만 입력칸이 생긴다. 완료하면 활성 목록에서 빠지고 하루 기록에 남는다. **실행 취소**는 다시 열림 기록을 남긴다. 일반 메모를 자동으로 할 일로 만들지 않는다.
7. **하루 보기**만 큰 본창을 연다. 로고에서 하루의 흐름 / 항상 위 / 숨기기 / 종료. 끝내려면 **트레이 → 앱 종료**다.

기본 실행은 **규칙 연결**이다. 업무 라벨을 매번 달지 않아도 같은 표현이 이어지면 한 업무로 묶고, “나중에 보기” 같은 요청은 수행과 구별한다. 설정에서 로컬 보조를 직접 켠 경우에만 동봉 엔진이 127.0.0.1에서 잠시 뜬다. 원문 저장은 분석을 기다리지 않는다. 원문은 인터넷·클라우드 AI로 나가지 않는다. Ollama 설치·serve·pull은 하지 않는다.

## 본창

1. 왼쪽은 하루의 흐름 / 할 일 / 설정, 가운데는 날짜와 **시간순 / 파노라마 / 업무별**이다.
2. 파노라마는 개별 카드가 아니라 업무 구간과 전환 순서를 먼저 보여 준다. 구간을 누르면 그 원문·사진·파일이 펼쳐진다. 중간 요청은 수행 흐름을 끊지 않는 마커로 남는다. 시각은 관측된 기록의 시각 또는 범위이며, 공백을 휴식·집중으로 해석하지 않는다.
3. 기록이나 업무를 고르면 오른쪽에 상세 또는 업무 맥락이 열린다. 고르지 않으면 빈 열을 두지 않는다.
4. 업무 맥락에는 다음 행동 한 줄, 마지막 일반 메모, 관련 자료가 있다. 완료 이벤트가 마지막 기록을 밀어내지 않는다. 다음 행동은 200자, 공백만 저장하지 않으며 몰래 자르지 않는다.
5. **이어서 기록**은 캡슐에 그 업무를 연결한다. 타이머나 외부 앱을 복구하지 않는다.
6. **하루 정리**는 본문과 파일을 기본 미선택으로 연다. 고른 원문만 미리보기·복사·ZIP에 들어간다. 다른 날짜 근거는 지금 기록 ID를 직접 넣는다. 날짜 탐색 UI는 없다.

## 저장과 보안

메모와 첨부 사본은 이 PC의 로컬 폴더에 둔다. 앱 자체 암호화는 없다. Windows 로그인 시 시작은 꺼져 있다. 클라우드 동기화·클라우드 AI·Jira API는 없다. 설정 로컬 보조의 기본은 **규칙만**이다. 로컬 보조만 동봉 엔진을 켠다. 다음 실행에서 Off였던 저장소는 한 번 규칙만으로 올린다. 원문을 인터넷으로 보내지 않는다. 설정에서 **저장 폴더 열기**로 기존 자료를 복사·백업할 수 있다. **하루 정리**의 복사·ZIP은 그대로다.

## 아직 없는 기능

휴지통 UI, 설정 안의 복원 마법사, 다른 날짜 근거 탐색. 타이머·집중시간·범용 챗봇·자동 보고·결제·클라우드 요약은 이 핵심 버전에 넣지 않았고, 이전 확대 계획은 보류다.
