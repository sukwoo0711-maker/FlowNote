# FlowNote 사용 안내

기록일: 2026-09-15  
대상 빌드: `artifacts/win-x64/FlowNote.Desktop.exe` (win-x64 self-contained)

## 실행

```powershell
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
.\artifacts\win-x64\FlowNote.Desktop.exe
```

- 일반 데이터: `%LOCALAPPDATA%\FlowNote\live`
- 데모 데이터: `.\artifacts\win-x64\FlowNote.Desktop.exe --demo` → `%LOCALAPPDATA%\FlowNote\demo`  
  격리하려면 `--data-root <빈 폴더>`를 붙인다. 샘플 하루는 데모에서만 한 번 만든다.
- `--smoke`와 `--demo`를 같이 쓰면 샘플 시딩을 하지 않는다.
- 끝내려면 메인 창의 X가 아니라 **트레이 아이콘 → 앱 종료**를 사용한다. X는 트레이로 숨긴다.

## 기록

1. 작업 영역 오른쪽 위의 **한 줄 캡슐**에 메모를 입력한다. **Enter** 또는 인라인 기록 버튼으로 남긴다. Ctrl+Enter도 같다. 한글 조합을 확정하는 Enter는 기록하지 않는다. **Shift+Enter** 또는 로고 메뉴의 긴 메모로 여러 줄을 연다.
2. 카메라 아이콘은 **한 번 영역을 드래그**해 초안 첨부한다. 자동으로 타임라인에 올리지 않는다. 클립 아이콘·Ctrl+V·끌어다 놓기로 파일을 붙인다. 실행 파일·스크립트·바로가기는 거부한다. 파일당 25MB, 기록당 10개. 텍스트와 첨부가 모두 없으면 기록은 비활성이다. 이미지만 있어도 기록할 수 있다.
3. 업무 연결은 필수가 아니다. 로고 메뉴의 **연결 업무 선택** / **연결 해제**, 또는 본창 **이어서 기록**으로 칩을 단다. 화면에서 다른 업무를 열어 보기만 해서는 작성 중 초안이 바뀌지 않는다. 초안이 다른 업무와 겹치면 계속/재연결/취소를 고른다.
4. 저장이 되면 입력칸은 비고, `HH:mm 기록됨`은 입력칸 위 상태 문구다. 그 문구를 본문으로 다시 저장하지 않는다. 같은 세션에서는 칩이 남는다. 빈 상태로 다시 켜면 미연결이다.
5. **할 일** 아이콘으로 작은 패널을 연다. `+ 할 일 추가` 후에만 입력칸이 생긴다. 체크로 완료하면 목록에서 사라지고 타임라인에 완료 이력이 남는다. 완료는 삭제가 아니다. 근거 없는 완료도 된다. **실행 취소**는 다시 열림 기록을 남긴다. 시계 아이콘은 오늘 최신 3개다.
6. 로고에서 하루의 흐름 / 항상 위 / 숨기기 / 종료. 창 제목줄이 없으므로 끝내려면 **트레이 → 앱 종료**다.

## 본창

1. 왼쪽은 하루의 흐름 / 할 일 / 설정, 가운데는 날짜와 **시간순 / 파노라마 / 업무별**이다.
2. 파노라마를 고르면 아직 없다는 안내만 나온다. 엔진을 만들지 않았다.
3. 기록이나 업무를 고르면 오른쪽에 상세 또는 업무 맥락이 열린다. 고르지 않으면 빈 열을 두지 않는다.
4. 업무 맥락에는 다음 행동 한 줄, 마지막 일반 메모, 관련 자료가 있다. 완료 이벤트가 마지막 기록을 밀어내지 않는다. 다음 행동은 200자, 공백만 저장하지 않으며 몰래 자르지 않는다.
5. **이어서 기록**은 캡슐에 그 업무를 연결한다. 타이머나 외부 앱을 복구하지 않는다.
6. **하루 정리**는 본문과 파일을 기본 미선택으로 연다. 고른 원문만 미리보기·복사·ZIP에 들어간다. 다른 날짜 근거는 지금 기록 ID를 직접 넣는다. 날짜 탐색 UI는 없다.

## 저장과 보안

메모와 첨부 사본은 이 PC의 로컬 폴더에 둔다. 앱 자체 암호화는 없다. Windows 로그인 시 시작은 꺼져 있다. 클라우드 동기화·클라우드 AI·Jira API는 없다. 설정에는 로컬 보조(끔 / 규칙만 / 로컬 보조)가 있으며 기본은 **규칙만**이다. 원문을 외부로 보내지 않는다. 설정 화면의 백업 단추는 없다. 폴더 복사로 백업할 수 있으나 앱이 복원 절차를 보여 주지는 않는다.

## 아직 없는 기능

파노라마 본화면, 휴지통 UI, 전역 단축키, 설정 백업/복원 단추, 다른 날짜 근거 탐색. 결제·체험판·클라우드 AI 요약·자동 수집은 이 빌드에 넣지 않았다. 로컬 모델 실측은 Ollama가 있을 때만 가능하다.
