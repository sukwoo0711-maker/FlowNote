# FlowNote 0.5.5 — 포스트잇 캡처와 한눈에 보이는 종이

기준: v0.5.4 / 48af5f3. 원문·첨부·업무 연결·파노라마 순서와 사용자 데이터는 유지한다.
새 모델·타이머·폴더·제목 양식을 추가하지 않는다.

## 변경
- 플로팅 기록 면은 어두운 알약이 아니라 `#FFF9E8` 포스트잇이다. 520×52 DIP, 모서리 3, 잉크 `#1C1C1E`를 유지한다.
- placeholder는 `한 장에 적으세요`다. 제목 칸은 없다.
- 최근 기록 3개는 한 줄 로그가 아니라 본문이 보이는 작은 종이다.
- 빈 하루는 빈 종이를 누르면 바로 적는다. `아직 기록이 없습니다`와 `첫 기록 남기기`는 유지한다.
- 시간순·파노라마 메모는 300 DIP 종이다. 파노라마에서 `원문 보기`를 없애고 종이 자체가 원문이다.
- Peek·긴 메모·할 일 행·첨부는 같은 종이/책상색을 쓴다.
- 캡슐을 큰 메모장으로 되돌리지 않는다. 여러 줄은 기존 긴 메모 종이에서만 커진다.

## 검증과 제한
- Core 101 + Infrastructure 81 = 182 통과.
- WPF smoke와 배포 ZIP 재실행 결과는 릴리스 `verification.json`에 기록한다.
- 사람의 한국어 IME 조합, 150% 이상 배율, 장기 실사용, 코드 서명, 신규 LLM 의미 평가는 NOT RUN이다.
- 운영 앱과 운영 데이터는 변경하거나 강제 종료하지 않는다. 테스트만 격리 저장소를 사용한다.
