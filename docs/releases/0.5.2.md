# FlowNote 0.5.2 후속 수리

기준: v0.5.1 / df76835e24945eb08b91cffe816da31e62e9097f.
작업: mango의 별도 git worktree. 실행 중인 v0.4.0과 운영 데이터는 변경하지 않는다.

## 수정 범위

- 검색을 실행한 질의와 입력 중인 텍스트를 분리했다. 데이터/분석 갱신으로 검색이 하루 목록으로 되돌아가지 않는다.
- 검색 결과 없음, 선택한 원문, 날짜 범위가 유지된다. 날짜·보기 전환이나 빈 검색 실행은 검색을 해제한다.
- 파노라마는 공식 완료 → 다시 열림 → 재완료를 모두 표시한다. 다시 열림을 업무 시작시간으로 추정하지 않는다.
- 추론의 OperationCanceledException이 호출자 취소인지 모델 제한시간인지 구분한다. 모델 timeout 하나로 worker 루프가 끝나지 않는다.
- 호출자 종료로 중단된 분석은 RetryWait로 보존한다. 최대 실행 시도 3회와 5/30초 간격은 유지하며 반복 취소도 시도 횟수에 포함한다.
- 최종 lease가 만료된 작업은 failed로 종료한다. 아직 유효한 lease는 그대로 유지한다.
- 결과 적용 시 현재 lease 만료 여부를 확인한다. 만료된 분석은 원문·할당을 변경하지 않는다.
- 설치본 버전은 패키지 버전에서 전달한다. 모델·실행기·스키마 확장은 없다.

## 검수

기준 테스트: Core 96 + Infrastructure 70.
수정 전 queue 반례 4개, 다시 열림 누락 1개, 실제 WPF smoke의 검색 갱신 오류를 재현했다.
수정 후 Core 97 + Infrastructure 77 = 174 통과 / 0 실패.
WPF smoke는 검색 결과와 빈 결과의 갱신 보존, A/B 흐름, 원문·첨부, 완료/실행 취소, 520×52 캡슐을 검사한다.
실제 실행 빌드와 새 압축 해제 패키지의 검수는 배포 verification.json에 별도로 기록한다.

## 제한

규칙 연결과 기존 저장을 수리했다. 로컬 LLM 의미 평가를 새로 수행하지 않았다.
사람의 한국어 IME, 150% 이상 배율, 장시간 실제 업무 사용성은 NOT RUN이다.
설치 EXE는 기존 Inno Setup으로 컴파일한다. 운영 설치의 무인 교체와 실행 중 앱 강제 종료는 하지 않는다.
이번 범위는 worker 전체 수명과 모든 UI DB 경로의 완전한 비동기 재설계가 아니다.
비협조적인 외부 엔진의 긴 종료, 자연어 역할 판정의 일반화 한계는 남아 있다.
