# FlowNote 0.5.3 — 수정한 기록과 화면 상태 보존

기준: v0.5.2 / a1ef57b49203321e18fb2d17784e67b90be46231.
새 모델·타이머·테마·스키마를 추가하지 않은 유지보수 버전이다.

## 달라진 동작

- 목록이 갱신돼도 선택한 메모의 원문 상세와 선택 표시가 유지된다.
- 열어 둔 업무 상세가 데이터 갱신 직후 닫히지 않는다.
- 최근 기록의 작은 상세에서 수정한 본문을 바로 확인한다.
- 최근 기록을 열면 작은 상세 패널로 전환한다. 이전 긴 메모 화면 뒤에 숨지 않는다.
- 삭제한 기록의 상세와 선택 ID를 정리한다. 원문은 기존 휴지통 정책을 따른다.
- 메모 본문을 수정하면 예전 본문에 대한 완료·요청 판정과 부차 요청을 무효화한다.
- 사용자 지정 업무 연결과 명시적 연결 해제는 유지한다. 역할은 불확실 상태로 돌아가며, 사용자 잠금을 자동 분석으로 덮지 않는다.
- 자동 연결은 재분석 대기 상태로 돌아간다. 새 본문에서 다시 연결하며 원문·첨부·수정 이력은 유지한다.

## 재현과 검수

수정 전 데이터 회귀 4건이 실패했다. 자동 연결·사용자 연결·연결 해제의
revision이 갱신되지 않았고, 삭제된 문장의 부차 요청도 남았다.
실제 WPF smoke에서는 목록 갱신 후 선택 손실, 작은 상세의 오래된 본문,
메인 상세 갱신 실패를 재현했다.
후보 빌드 테스트: Core 97 + Infrastructure 81 = 178 통과 / 0 실패.
기존 A/B 흐름·검색 보존·완료/실행취소·캡슐 검수도 함께 수행한다.
최종 커밋의 실행·압축 해제·재실행 검수는 릴리스 `verification.json`에 기록한다.

## 사용과 제한

설치본 또는 포터블 ZIP을 사용한다. 기존 앱을 트레이에서 종료한 뒤 업데이트한다.
기록 폴더 `%LOCALAPPDATA%\FlowNote\live`를 삭제하지 않는다.
이번 작업은 실행 중인 이전 앱을 강제 종료하거나 운영 DB를 수정하지 않았다.
기본 연결은 규칙 방식이며 AI 엔진·모델은 포함하지 않는다.

사람의 한국어 IME, 다중 모니터/150% 이상 배율, 장시간 실사용, 코드 서명,
신규 로컬 LLM 의미 평가는 NOT RUN이다. 화면 캡처와 자동 WPF 검수는
사람의 조작·접근성 검수와 구분한다.
자연어 연결의 일반화, 모든 DB/UI 경로의 비동기화, 비협조 엔진 종료는
이번 버전에서 해결됐다고 주장하지 않는다.
작업 정체성이 연결됐으나 수행 여부가 불확실한 기록의 표현은 후속 검토 대상이다.
