# FlowNote 0.5.4 — 퀵 입력과 포스트잇

기준: 9001d18 / 0.5.3. 원문·첨부·업무 연결·파노라마 순서와 사용자 데이터는 유지한다.

## 변경
- 퀵 단축키는 기본 Ctrl+Alt+Space. 충돌하면 Ctrl+Alt+N을 등록하고 트레이와 설정에 실제 키를 알린다.
- Windows 앱 단축키 ID 범위를 준수한다. 실패 원인의 Windows 오류 코드도 보존한다.
- 명시적 단축키와 Shift+Enter는 현재 보이는 편집기에 포커스를 준다. 여러 줄 초안을 숨겨진 한 줄 TextBox로 보내지 않는다.
- 일반 화면 갱신은 포커스를 가져오지 않는다. 단축키로 기존 초안을 지우거나 저장하지 않는다.
- 메모는 제목과 발췌 대신 원문 본문 한 덩어리로 표시한다. 줄바꿈을 유지한다.
- 하루 보기와 파노라마가 같은 포스트잇 본문 컴포넌트를 쓴다. 파노라마는 업무 연결·요청·복귀를 유지한다.
- 파노라마의 메모는 기본 펼침이며, 사용자가 접으면 갱신 중 그 선택을 보존한다.
- + 메모 버튼은 제목 양식 없이 퀵 입력으로 이동한다.
- 최근 사진·초안 첨부·하루 사진·파노라마·상세 사진을 누르거나 Enter로 확대 창을 연다.
- 확대/축소, 화면 맞춤, 100%, Ctrl+휠, Escape 닫기를 제공한다. 파일은 로컬에서만 읽는다.
- 큰 이미지는 긴 변 4096 픽셀 미리보기로 제한하고 표시한다. 원본 첨부는 변형하지 않는다.

## 검증과 제한
- Core 101 + Infrastructure 81 = 182 통과. 한 줄/여러 줄/이미지 단독의 단일 본문 규칙 포함.
- WPF smoke는 실제 RegisterHotKey/WM_HOTKEY 경로, 숨김 후 한 줄·여러 줄 포커스, 사진 확대와 오류 처리를 검사한다.
- mango에서는 기본 키 등록이 Windows 1409로 실패했다. 다른 프로세스가 사용 중임을 확인했으며 점유 프로세스를 종료하지 않았다.
- 별도 Tk 프로세스를 전경에 둔 상태에서 대체 단축키로 돌아와 실제 키 입력이 테스트 초안에 남는 것을 확인했다. 한국어 IME 실물 키보드 검수와는 다르다.
- 실제 배포 ZIP/설치 컴파일/다른 PC 검수 결과는 릴리스 verification.json을 따른다.
- 사람의 IME 조합, 150% 이상 배율, 장기 실사용과 LLM 의미 평가는 NOT RUN이다.
- 운영 앱과 운영 데이터는 변경하거나 강제 종료하지 않는다. 테스트만 격리 저장소를 사용한다.
