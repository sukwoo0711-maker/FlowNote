# FlowNote UI 재작업 패키지

이 패키지는 기존 앱의 UI 재작업 지시이며 실행 프로그램이 아닙니다.

파일:
- FlowNote_UI_Rescue_v1_1.md: UI 변경, 단계별 실행, 승인 기준.
- references/00-current-app.png: 사용자가 제공한 현재 앱 캡처. 실패 원인 분석용.
- references/01-concept-timeline.png: 앞선 컨셉 이미지. 톤과 시간축 표현 참고용이며, 승인된 데스크톱 구현 기준은 아닙니다.

worker에게 처음 보낼 지시:

"현재 저장소와 FlowNote_UI_Rescue_v1_1.md, 두 참고 이미지를 실제로 읽고 U0만 수행하라.
처음에는 기존 코드/단계/스타일 적용/템플릿/placeholder 바인딩을 조사한다.
파일이 없거나 이미지를 볼 수 없으면 그 사실을 보고하라. 읽었다고 가정하지 마라.
확인 가능한 원인만 보고하고, 기존 컴포넌트와 격리 fixture로 실제 WPF 프리뷰를 만든다.
운영 DB·시간·완료·첨부 로직을 훼손하거나 프레임워크를 교체하지 마라.
코드 수정 후 실제 캡처를 제출하고, 시각 승인 전 전체 화면으로 확장하지 마라.
Windows GUI가 없으면 시각/IME 검수는 NOT RUN이다."

이후 승인된 컴포넌트로 U1 플로팅 창 → U2 시간순 타임라인 → U3 파노라마 및 회귀를 한 단계씩 진행합니다.
