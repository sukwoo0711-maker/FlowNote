# FlowNote V3 — 작업 에이전트 전달 패키지

**목표:** 기존 캡슐을 보존하면서 ‘기록 → 업무 연결 → 다음 행동 → 이어하기 → 완료 → 선택 보고’를 하나의 실제 흐름으로 구현한다.

이 패키지는 지침·검수 계획·참고 자료다. 수정 앱, 검증된 코드, 판매 성과가 아니다.

## 전달 방법

1. 이 폴더를 에이전트가 읽을 수 있는 프로젝트 작업 공간에 둔다. 민감한 references는 공개 Git에 커밋하지 않는다.
2. 현재 FlowNote 저장소를 에이전트가 실제로 읽고 수정할 수 있게 제공한다.
3. `00_START_AGENT.md`의 시작 프롬프트를 작업 대화에 붙여넣는다.
4. 결과로 컴포넌트 표본만이 아니라 실제 빌드·OS 캡처·전체 흐름·테스트를 받는다.

## 파일

- `00_START_AGENT.md`: 시작 지시.
- `01_MASTER_WORK_ORDER.md`: 독립적으로 읽을 수 있는 전체 제품·동작·데이터 계약.
- `02_ACCEPTANCE_TESTS.md`: 65개 검수 계획. 초기 상태 전부 NOT RUN.
- `03_VISUAL_CONTRACT.md`: 캡슐·본창·업무 맥락·보고 화면의 구조/상태.
- `design_tokens.json`: 기본 디자인 수치. 런타임 설정 기능 추가 요구가 아님.
- `fixtures/`: 격리된 합성 시연 시나리오와 로그. 실제 PNG는 에이전트가 테스트 자료로 생성한다.
- `references/`: 목표 캡슐1장과 현재 앱5장. 모두 실행 전 참고, 공개 배포 금지.

가격·유료 체험·결제·마케팅은 구현하지 않는다. 사용자 검증과 상품성은 별도이며, 실제 사람 없이 PASS 처리하지 않는다.

중간 승인 없이 P0~P5를 진행하되, 환경/세션이 실제 허용하는 범위에서 실행한다. 자동 재개·밤새 완주·디자인 만족·판매 성공을 보증하는 문구가 아니다.
