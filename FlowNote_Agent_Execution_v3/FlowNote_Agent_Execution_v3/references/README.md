# 이미지 기준과 출처

이 폴더의 PNG는 현재 대화에서 사용자가 제공한 이미지의 사본이며, 이번 에이전트 작업의 완료 증거가 아니다. 앱 배경이나 실행 화면으로 재사용하지 않는다.

| 파일 | 역할 |
|---|---|
| 01_target_capsule.png | 사용자가 지정한 목표 캡슐 외형. 높이·가로형·작은 패널·톤의 참고. 이미지 밖 홍보 주석은 제외 |
| 02_current_main.png | 현재 본창의 개선 전 상태. 최종 목표 레이아웃이 아님 |
| 03_current_capsule_todo.png | 현재 TODO가 있는 캡슐 |
| 04_current_capsule_empty.png | 현재 빈 TODO 상태 |
| 05_current_capsule_saved.png | 현재 성공 표시 상태; 입력 텍스트와 분리해야 함 |
| 06_current_capsule_typing.png | 현재 입력 상태 |

이 이미지들에는 파일 경로 등 사용자 작업 환경의 일부가 보일 수 있다. 구현 담당자가 비공개 작업 참고로만 사용하며, 마케팅·공개 저장소·제품 번들에 넣지 않는다. 실제 납품 시연은 합성 자료로 새로 캡처한다.

설계 근거로 읽은 기존 문서: FlowNote_Paid_Product_Strategy_v1.md(제품 흐름·제안 범위), 01_FLOATING_CAPSULE_OVERRIDE.md(v2 외형), 01_MASTER_IMPLEMENTATION_PROMPT.md(기존 데이터·보존 계약). 이번 실행에서는 V3의 명시적 우선순위가 적용된다. 과거의 단계별 승인 대기 규칙을 되살리지 않는다.
