# V3 검수 계획과 결과 양식

이 파일의 모든 항목은 실행 전 계획이다. 초기 상태는 NOT RUN이며 통과한 결과가 아니다.

기존 테스트를 유지한다. PASS는 실제 실행 증거가 있을 때만, FAIL은 관찰된 불일치, BLOCKED는 필요한 환경/승인이 명확한 경우다. 부분 통과를 전체 통과로 세지 않는다. 회귀·장애 주입은 합성·임시 저장소에서만 수행한다.

## 화면 증거 최소 세트

기본 캡슐 / 업무 연결 입력 / 성공 상태 / 다음 행동 편집 / 업무 맥락 / 빈 날짜 / 1개 기록 / 혼합 기록 / 보고 선택 / 보고 미리보기 / 실패 / 좁은 창.

OS 캡처 원본에 DPI와 실제 창 경계를 별도 기록한다. RenderTargetBitmap과 실제 화면 캡처의 파일명을 구분한다. 둘을 합쳐 같은 수준의 OS 검증 증거로 표시하지 않는다.

## 사람 검증 과제

절차 설명 없이 메모 기록·이미지 첨부·업무 연결·다음 행동·재개·완료·선택 보고를 요청한다. 도움 요청, 잘못된 클릭, 되돌림, 과제 완료 여부, 원문을 되찾을 수 있었는지 기록한다. 사내 원문을 수집하지 않는다. 시간 감소·구매 의향은 실제 비교/결제가 없는 한 미검증이다.

## 인수 보류

데이터/초안 유실, 숨은 업무 재연결, 완료 이력 오류, 선택하지 않은 내용의 유출, migration 실패 시 원본 손실, 캡슐 세로 회귀, 실제 이미지·실행 증거 위장, 정책 우회가 있으면 인수를 보류한다. 미실행 환경을 최종 통과로 대신할 수 없다.
