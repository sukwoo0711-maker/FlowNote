# 지금 worker에게 전달할 시작 지시

아래 문장과 함께 이 폴더 전체를 현재 agent가 읽을 수 있는 경로에 제공한다.
이 패키지는 플로팅 창 변경 명세다. 완성 앱이나 검증된 실행 코드가 아니다.

---

이번 작업은 FlowNote의 **플로팅 창 하나를 세로 메모장에서 가로 캡슐로 교체**하는 것이다.
기존 UI를 유지한 채 크기와 색상만 조정하는 작업이 아니다.

먼저 실제로 읽어라:
- `01_FLOATING_CAPSULE_OVERRIDE.md`
- `02_ACCEPTANCE.md`
- `design_tokens.json` — 디자인 기준 데이터. 앱의 런타임 설정 프레임워크를 새로 만들라는 뜻이 아니다.
- `references/01_REJECTED_tall_notepad.png` — 폐기할 형태
- `references/02_TARGET_floating_capsule.png` — 따라야 할 외형
- 현재 저장소의 플로팅 View/ViewModel/Style/창 크기 복원 코드

파일을 볼 수 없으면 실제 탐색 경로와 누락 항목을 보고한다. 이미지를 봤다고 가정하지 마라.

## 우선순위 변경

이번 v2 명세가 기존 F01 및 UI 재작업서의 플로팅 지시를 대체한다.
기존 360×500, 80~96 DIP 기본 편집기, 기본 제목표시줄 허용,
상시 하단 TODO, 빈 상태 높이280~340, 단계별 사용자 승인 대기는 폐기한다.

저장·초안·첨부 사본·완료 이력·보안·기존 데이터는 보존한다.
새로 허용하는 기능은 **사용자가 누른 1회 영역 캡처**뿐이다.
자동 감시·AI·Jira API·클라우드·녹화는 추가하지 않는다.

## 끝까지 수행할 범위

1. 실제 기존 코드/실행 화면과 충돌 명세를 확인한다.
2. 제목 표시줄 없는 520×52 DIP 가시 캡슐을 실제 플로팅 실행 경로에 적용한다.
3. 로고 메뉴, 한 줄 입력, 인라인 기록, 영역 캡처, 첨부, 할 일, 최근 기록을 연결한다.
4. 최근 기록/TODO는 아래의 작은 패널로만 펼친다. 기본 상태에는 없다.
5. 저장/초안/첨부/완료·재열기 서비스를 재사용한다.
6. 실제 Windows 창에서 실행·캡처·수정한다.
7. 같은 프로세스의 기존 메인 타임라인 연결과 데이터 회귀를 확인한다.
8. 실행 빌드·소스·실제 캡처·PASS/FAIL/NOT RUN을 제출한다.

**U0 표본 승인 대기로 멈추지 마라. 메인 전체 디자인이나 파노라마 재설계로 범위를 넓히지도 마라.**

## 이번 작업의 외형 하드 게이트

- 첫 화면은 한 줄 캡슐, 높이52 DIP, 끝 반경26 DIP다.
- 기본 Windows 제목표시줄·최소화/최대화/X 버튼이 플로팅에 보이지 않는다.
- `오늘 / 고정됨 / 접기 / 숨기기` 텍스트 버튼 줄이 없다.
- 상시 큰 메모칸·‘남은 할 일0개’ 빈 영역·하단 추가 입력란이 없다.
- 짙은 청록–슬레이트 표면과 밝은 글자이며, 흰 사각 입력폼이 아니다.
- 입력만 할 때 높이가 커지지 않는다.
- 패널0 상태의 실제 창 bounds도 작아야 한다. 보이지 않는 큰 영역으로 다른 앱 클릭을 막지 않는다.
- 이미지가 첨부되면 파일명만이 아니라 실제 썸네일이 보인다.
- 캡처 아이콘은 장식이 아니라 사용자 선택 영역을 초안 첨부로 받는 동작이다.

Enter는 한 줄 메모 입력에서만 기록으로 처리한다.
창 전체의 기본 버튼/KeyDown으로 TODO 생성, 메뉴 선택, IME 확정까지 기록해 버리지 마라.
긴 메모는 Shift+Enter로 열고 Enter 줄바꿈 / Ctrl+Enter 기록을 쓴다.

실제 배경 블러는 기본 요구가 아니다. 반투명 색·윤곽·깊이로 참고의 유리풍을 구현한다.
실제 블러가 없다고 흰 사각 창으로 되돌리거나 프레임워크를 바꾸지 마라.

## 자율 검수

명세의 C0~C4를 순서대로 수행하되 중간 승인을 기다리지 않는다.
실제 실행 화면을 확인하며 최대3회의 수정 사이클을 수행한다.
기능/시각 실패와 환경상 미검증을 구분한다.
`RenderTargetBitmap`만으로 OS 창 검수를 통과시키지 않는다.
사용자 데이터·보안·권한 문제를 우회하지 않는다. 막힌 부분은 따로 보고하고 안전한 독립 작업을 계속한다.
